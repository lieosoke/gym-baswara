# Gym Baswara

Gym Baswara adalah aplikasi pencatat latihan untuk Android. Aplikasi ini mencatat sesi latihan pengguna secara luring dan menyinkronkannya ke server.

## Fitur

* **Pencatatan Latihan:** Aplikasi mencatat sesi latihan harian pengguna.
* **Berjalan di Latar Belakang:** Sesi latihan tetap berjalan meskipun pengguna menutup aplikasi.
* **Penyimpanan Luring:** Aplikasi menyimpan data latihan di perangkat menggunakan Room Database.
* **Sinkronisasi:** Aplikasi mengirimkan data latihan ke server saat perangkat daring.
* **Pratinjau Latihan:** Pengguna dapat meninjau data latihan sebelum menyimpannya ke basis data lokal.

## Teknologi

* **Klien Android:** Kotlin, Room Database, dan Retrofit.
* **Server:** Go, framework Gin, dan MongoDB.
